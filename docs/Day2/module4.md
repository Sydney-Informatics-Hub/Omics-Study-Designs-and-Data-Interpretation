# Module 4 — Bias Identification and Data Quality Assessment

!!! info "Learning objectives"

    - By the end of this module, participants should be able to:

        - List common sources of technical bias in omics and connect each to plausible patterns in the data.
        - Define a confounder in intuitive terms and, using metadata tables, judge whether key variables are balanced across groups or likely to bias results.
        - interpret a PCA and other plots in terms of what drives sample clustering, using metadata to distinguish technical from biological sources of variance.
        - Participants will be able to interpret Log Expression plots and describe what systematic shifts across samples indicate about data quality or normalisation failure.
        - Decide when batch correction is and is not appropriate based on the recorded design and anticipate the risks of over‑ or under‑correction.
