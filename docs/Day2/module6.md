
# Module 6 — Interpretation Traps and Common Pitfalls​
(Reading figures and results with the scepticism the data deserves)
!!! info "Learning objectives"
    - By the end of this module, participants will be able to

        - Distinguish valid from invalid conclusions drawn from PCA and UMAP visualisations — recognising that not everything visible in a plot is biologically meaningful or statistically warranted
        - Evaluate a reported finding using both statistical significance and effect size together, and explain why applying fixed thresholds mechanically produces misleading conclusions in both small and large studies.
        - Explain how false discovery rate behaves differently in small exploratory studies versus large well-powered cohorts, and recognise which FDR approach is appropriate given a study's size and goals.
        -Critically read a published figure or their own results, judge which conclusions are well-supported versus speculative, and identify what would be needed to make the weaker conclusions more convincing.
