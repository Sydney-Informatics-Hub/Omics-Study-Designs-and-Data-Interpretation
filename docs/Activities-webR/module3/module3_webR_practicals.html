Three hands-on exercises.

Each tab below contains one exercise with a few runnable code blocks. Click Run to execute a block, variables persist across blocks within a tab, so run them in order the first time through.

Working habit. Before running a block, make a short guess about the output. If your expectation differs from the result, pause and think about why; that mismatch is where the idea becomes clear.
